# ZakatFlow V9

Commercial UX layer over V8 foundation. Includes polished bilingual shell, interactive assessment simulator, workflow UI, dashboard, and enterprise navigation.

## Run
1. Copy `.env.example` to `.env.local`.
2. Set Supabase URL and anon key.
3. `npm install`
4. `npm run check`
5. `npm run dev`

## Important
The assessment screen contains a clearly labeled interactive simulator. Production calculations must use the server-side engine, persisted market-price/FX snapshots, approved rulesets, and Supabase transactions/RLS.
