# Configurable plans and owner control contrast

Proposed launch prices per institution: Professional SAR 199/month or 1,990/year, up to five active users; Advanced SAR 399/month or 3,990/year, up to fifteen. Annual prices equal ten monthly prices. Published prices are explicitly proposed, exclude applicable taxes and require manual confirmation/activation. No payment, renewal, provider, SMTP or Google configuration is enabled or changed.

Professional includes assets, cash/banks, VAT/invoices, Zakat and debts/financing. Advanced adds budgets, investments/participations and role customization. The financial foundation (assets and liquidity), existing reading/export, basic roles and account/support functions remain available. The catalog exposes only active published plans to authenticated users; unpublished/custom drafts stay in the owner register. Owners can create and edit AR/EN names/descriptions, price, currency, interval, seats, included modules/features, publication and proposed-price flags, with live owner authorization, reason, audit and optimistic revision checks.

Paid activation snapshots the entitlement set and plan quote. Editing a catalog plan does not change existing agreements; an explicit owner activation is needed to change them. Legacy institutions and prior agreements retain core access. Trial institutions retain every trial capability and five seats. The database enforces publication validation and per-plan seat ceilings. No existing institution is automatically converted, charged or downgraded.

Module availability governs new writes. Existing data remains readable/exportable within unchanged RLS and member permissions after a downgrade. The same database write guard checks capabilities for direct and SECURITY DEFINER writes and old/new organization scopes. Internal nested budget bookkeeping can update actuals only; it never bypasses expiry or permits manual plan edits. Pricing is not an authorization source in the browser. Unsupported/new capabilities are rejected rather than silently granted.

The owner plan editor lists all current prices, limits and modules; monthly/yearly variants share an explicit family. Plans are unpublished by default when customized. Native select/options receive explicit foreground/background colors in all owner themes, with browser contrast checks and screenshots. Customer pricing is bilingual/responsive, uses dynamic published data, shows complete yearly cost and monthly equivalent, and explains manual activation without creating a transaction.

Verification includes schema/permission regressions, plan snapshots, stale admin edits, seat ceilings, direct/definer denials, AR/EN pricing toggles, custom plan publication from the owner UI and native dropdown contrast across four owner themes. The historical schema fixture is retained, with a narrowly generated schema delta for this migration, checked against complete fresh Supabase history. All release evidence and any remaining limitations are recorded in the PR. Production schema must be applied before releasing the new API/UI, and installed migration history aligned to the committed version after verifying the SQL digest.
