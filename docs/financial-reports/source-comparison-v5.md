# V5 — real prior-year growth and annual preview

Source monitoring continues to default to fiscal months 1–12. A permanently visible scope label now shows fiscal year, selected month range, currency and comparison year. Acceptance screenshots separately capture the full annual view and a deliberately selected month; the latter must not be presented as the default annual UI.

An authorized prior-year saved plan can supply comparison figures through the same existing financial_budget_report RPC. A compatible plan must have the same institution, currency, entity, cost center, scenario, fiscal-start month/day, and exactly the previous fiscal year. The UI automatically chooses only a unique compatible prior plan; multiple eligible versions require explicit selection. Users can disable comparison. Both plans are authorized before report execution and current permissions are checked again before returning either result. Foreign institution or incompatible comparison scopes fail closed. No admin client, write, migration or parallel actuals store.

Growth uses exact decimals: `(current − previous) / abs(previous) × 100`. Utilization changes use percentage points. A zero prior value shows a non-comparable label; missing, invalid or incomplete recognized actual comparison has no growth arrow. Expense growth is red, expense decline green, flat neutral. Budget, forecast, variance and utilization direction are neutral, not automatically classified as better/worse. Legacy manual actual and gross cash are never used as the prior recognized actual. Selected-period unmapped amounts suppress actual, variance and utilization growth rather than suggesting a complete comparison.

Comparison provenance, previous figures, calculated changes, units and availability status are included in CSV/XLSX. No-comparison exports preserve the existing shape. The linked monthly source grid remains read only. Design/sidebar remain unchanged, apart from displaying real comparison indicators and an explicit scope label.
